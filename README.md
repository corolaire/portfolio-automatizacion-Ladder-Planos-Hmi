# # Control de motor trifásico con PLC (ladder) y HMI

Ejercicio de arranque/parada con enclavamiento, pasado de un esquema
eléctrico (CADe SIMU) a lógica ladder, con pantalla HMI.

## Qué hace
- START arranca el motor y se enclava.
- STOP corta el motor.
- Lámpara verde: motor en marcha. Lámpara de apagado: motor detenido.

## Archivos
- control-motor-plc-hmi.json: proyecto del simulador
- capturas/: ladder, tags y HMI en los dos estados
